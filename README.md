# QubarStream - Enterprise Media Downloader

> Engineered by **Qubartech** • Universal 4K & Lossless Audio Downloader

QubarStream is a high-throughput, enterprise-grade Next.js application built by **Qubartech** for downloading high-definition video and audio from **YouTube** (including 4K UHD and Shorts), **Instagram** (Reels and Carousels), **Facebook** (Watch and Reels), and **Telegram** (Direct CDN).

---

## 🌟 Key Features

- **Multi-Network Support**:
  - **YouTube**: 4K Ultra HD (2160p), 2K Quad HD (1440p), 1080p Full HD, 720p HD, and MP3 320kbps audio.
  - **Instagram**: Reels, post videos, IGTV, and carousels with direct video proxy.
  - **Facebook**: Public watch videos, Reels, and clips in HD/SD MP4.
  - **Telegram**: Public channel videos and media posts with direct CDN extraction.
- **Qubartech Smart Muxer**: Bundled `ffmpeg` with audio and video stream merging for zero playback errors.
- **In-Browser Video Preview**: Play videos directly before saving.
- **One-Click Clipboard Paste**: Instant paste and URL platform detection.
- **Local Download History**: Keeps track of recent downloads in browser storage.
- **Sleek Glassmorphic UI**: Built with Next.js 15, Tailwind CSS v4, and shadcn/ui.

---

## 🚀 Quick Start

### Prerequisites

- Node.js 18+
- Python 3 with `yt-dlp` installed

### Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Or build for production
npm run build
npm start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
